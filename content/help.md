# Help

Click a page link, or type a command below.
Documents are commands: `index`, `bio`, `research`, and `help`.

## Appearance

Use `theme dark`, `theme light`, or `theme system` to change appearance. System follows your device's appearance. Your choice is remembered in this browser.

## Commands

- `index` return to the home page
- `bio` read about me
- `research` view my research interests
- `ls [dir]` list a directory (try `ls /bin`)
- `cat <path>` print a document without clearing the screen
- `head -n 5 index` print the first five lines
- `tail -n 3 bio` print the last three lines
- `cat research | grep memory` filter lines
- `find /bin -type f` list command files
- `tree` draw the directory tree
- `more bio` page a document (space/b/q)
- `less bio` page with PageUp/PageDown
- `cd /bin` change directory (`cd /` to return)
- `clear` clear the screen
- `cat bio | wc -l` count lines
- `whoami` show the site owner's name
- `exit` return to the home page

## Keyboard

History: ↑/↓ or Ctrl-P/N. Complete: Tab. Cancel: Ctrl-C.
Clear: Ctrl-L. Return home: Ctrl-D on an empty line.
